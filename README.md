# AA 账本

出去玩 AA 分账的小程序。Node.js（仅依赖 `pg`）+ PostgreSQL，前端无框架。

- 管理员登录后创建「一次游玩」，把分享链接（`/t/<密钥>`）发到群里；朋友打开链接、选「我是谁」就能记账，不用注册。
- 每笔账：金额、谁付的、谁参与（默认全员）、按份数或指定金额分摊、类别、备注、截图（最多 9 张，前端压缩成 JPEG）。
- 结算：按「最少转账笔数」给出谁转给谁；可标记「已转」（支持部分金额）、撤销；收款码跟着人走，跨游玩共用。
- 结清后锁定账单，只有管理员能解锁；所有改动写进操作记录。
- 统计：每次游玩的人均 / 日均 / 每人垫付与应摊 / 类别 / 每天；管理员有年度汇总。
- 结算长图：前端用 canvas 生成 PNG，可保存或分享。
- 多币种：人民币、港币、新台币、日元、新币、马币、澳元、美元。结算统一折算成人民币；每次游玩每个币种一个统一汇率（首次使用自动填当日市场汇率 open.er-api.com，可改，改了会重算该币种所有账目）；外币账可直接填「实付人民币」（刷卡账单），不按汇率算。

分摊与结算算法在 `public/settle.js`，服务器和浏览器共用。金额全部以「分」为整数保存，除不尽的零头按最大余数分配，保证总和不差一分。

## 目录
- `server.js` 接口与静态文件；`schema.sql` 启动时自动执行（幂等）
- `public/` 前端；`deploy/` systemd 与 nginx 配置样本；`tests/` 测试

## 命令
    node server.js create-admin <用户名> [密码]   # 建管理员 / 重置密码
    node server.js clean-uploads                  # 删除没被引用的图片文件
    sh tests/run.sh                               # 算法 + 接口测试（用 zz* 临时数据，跑完清理）
